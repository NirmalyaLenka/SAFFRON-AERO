# Changelog

## 0.1.0 — Initial experimental release

- Added ESP32 Arduino/PlatformIO firmware scaffold with persisted configuration, schema/checksum checks, recovery states, local API and access-point fallback.
- Added phase-aware provisional profiles and strict output lockouts for unverified hardware.
- Added a single Flask dashboard with explicit simulator mode, device-authoritative mode, local chart rendering, CSV export and experiment notes.
- Added saffron environment research summary, bibliography, engineering safety guides and experimental problem-solution report.
- Added a host-side recovery policy model and tests. No claim is made that the firmware has been flashed or that physical controls have been validated.
